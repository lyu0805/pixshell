# PixShell v0.1.3

**Release date:** 2026-07-30
**Repository:** [lyu0805/pixshell](https://github.com/lyu0805/pixshell)

---

## 中文

### 概述

PixShell **v0.1.3** 聚焦性能与安全：Windows 端 UI 整体性能深挖（监控/标签/坞/终端全面提速）、macOS 凭据存储从弱加密升级为 AES-GCM、Web SSH 全离线化去 CDN 依赖、CSP 安全头加固，以及修复多项体验问题。

### 主要更新

#### 1. Windows 端整体性能深挖
- **监控面板**：去掉远端 sleep 1 命令，改用客户端 jiffies 差分实时计算 CPU%；列表与标题 dirty-check（未变化跳过重建）；Brush 静态冻结避免每帧分配
- **指标条**：渐变 Freeze + 跳过无变化 SetValue + Swap 栏补齐
- **迷你折线图**：环形缓冲 + 复用 PointCollection，避免每 3 秒 new 分配（Win10 监控侧栏不再卡顿）
- **标签切换**：修复切标签整屏闪黑问题（停止对 WebView2 做 RenderTargetBitmap 拍快照）
- **底部坞拖拽**：6px Border 手动拖拽高度 + 持久化 + 拖拽期间跳过终端 fit 风暴
- **SFTP 面板**：ConnectIfNeeded 移到线程池异步连接 + 防过期回调，切文件标签不再 UI 同步卡死
- **终端输入**：80ms 防抖 pixFit，避免拖坞/resize 风暴

#### 2. 安全加固
- **macOS 凭据加密升级**：XOR 掩码 → **AES-GCM (CryptoKit)** v2 格式；密钥派生自 SHA256(固定盐 + 用户名 + home)；旧值读时静默迁移回写；不走系统 Keychain，避免重装/ad-hoc 签 CDHash 变后弹窗
- **Web SSH 全离线化**：xterm.js / xterm.css / addon-fit.js 内置到 App Bundle，彻底脱离外部 CDN
- **双端 CSP 安全头**：HTML 响应加 Content-Security-Policy + X-Content-Type-Options: nosniff
- **Web 路径白名单**：Win `/web/*` 静态资源路径穿越拦截 + 非白名单 404

#### 3. 修复体验问题
- **GitHub #1**：切标签全屏闪黑（WebView2 黑洞遮罩 0.6-0.85s）— 已彻底修复
- **GitHub #2**：Win10 底坞高度不可拖拽 + 监控卡顿 — 已修复
- **SFTP 假绿堵死**：远端 tar 解压未执行时不再误报成功（`__PIXSHELL_RC` 标记校验 + 空输出视为失败）
- **airspace 穿层修复**：快速连接/重连后 WebView2 HWND 叠层问题已解决
- **Win ssh-keygen 探测重写**：修复 System32 内伪 PE 误判，按 PF OpenSSH → Git → PATH → System32 正确顺序解析
- **跨目录 SFTP 打包传输**：PackLocal 逐项 `-C parent base`，多选目录不再丢文件

## English

### Overview

PixShell **v0.1.3** delivers Windows UI performance overhaul, macOS AES-GCM credential encryption upgrade, fully offline Web SSH, CSP security hardening, and multiple UX fixes.

### Highlights

#### 1. Windows Performance Deep Dive
- **Monitor panel**: Removed remote sleep 1, client-side jiffies diff for real-time CPU%; dirty-check for lists/titles; frozen brushes
- **Metric bars**: Gradient freeze + skip unchanged SetValue + Swap bar support
- **Sparkline**: Ring buffer + reused PointCollection, no more allocations every 3 seconds
- **Tab switching**: Fixed full-screen black flash (removed RenderTargetBitmap snapshot on WebView2)
- **Bottom dock**: 6px Border manual drag + persistence + suppressed terminal fit during drag
- **SFTP panel**: Thread-pool async connection + stale callback guard
- **Terminal**: 80ms debounced pixFit to prevent resize storms

#### 2. Security Hardening
- **macOS credential encryption**: XOR → **AES-GCM (CryptoKit)** v2 format; silent migration on read; keychain-free to avoid TCC re-auth after reinstall
- **Web SSH fully offline**: Vendored xterm.js/css/addon-fit.js into app bundle, zero CDN dependency
- **Dual-platform CSP**: HTML responses include Content-Security-Policy + X-Content-Type-Options: nosniff
- **Web asset allowlist**: Win `/web/*` path traversal guard + non-allowlist → 404

#### 3. UX Fixes
- **GitHub #1**: Tab switch full-screen black flash — fixed
- **GitHub #2**: Win10 bottom dock non-resizable + monitor lag — fixed
- **SFTP false-green**: Remote tar extraction failure no longer reported as success (`__PIXSHELL_RC` marker validation + empty output → fail)
- **Airspace layering**: WebView2 HWND overlay issue after quick-connect/reconnect — fixed
- **Win ssh-keygen detection**: Fixed false-positive System32 pseudo-PE; now resolves PF OpenSSH → Git → PATH → System32
- **Cross-directory SFTP pack**: PackLocal per-item `-C parent base`, no more file loss in multi-dir selections
