# PixShell v0.1.6

> 发布日期：2026-08-02

PixShell **v0.1.6** 新增**无头模式**（MCP/CLI 后台静默运行）与**持久化 SSH 会话**（CLI 直连已存主机、会话按主机复用），并完成 16 项代码审查安全/稳定性修复；侧栏监控升级双色柱状图，连接失败弹出可交互错误面板。

---

## 新功能

- **无头模式**（双端）：`--headless` 启动时不弹 GUI，桥与 SSH/SFTP 会话完全自建，适合 Claude Desktop / MCP 后台调用；有头关闭自动拉起无头，有头打开自动接管
- **SSH 持久化**（双端）：CLI 加 `pixshell ssh <主机> [命令]` 直连已存主机（不再依赖打开 App）；无头 `connect` 按 hostId 复用已有会话，不再每次重连/重认证
- **快捷命令 CR 选项**：发送命令时可选末尾追加回车符

## 安全修复（16 项代码审查）

- Win SFTP 路径穿越：下载/上传接口加 `IsSafeLocalPath` 白名单，拒绝 `..` 与非 Downloads/Temp 路径
- Win EscapeArg 注入：改用 POSIX 单引号包裹，从根源消除 shell 元字符注入
- Mac WebDAV 备份密码：从明文 UserDefaults 迁移到 Keychain AES-GCM 加密存储
- Mac Keychain：读-改-写循环加 `NSLock` 消除并发竞态
- Mac QuickCommands：修复删光命令后重启被默认集覆盖的数据丢失问题
- Mac DownloadTasks：所有数组修改切回主线程，消除并发竞态
- Win LSP：专用 `_stdinLock` 消除 `lock(null)` 竞态

## 功能修复

- Mac Proxy IPv6：CONNECT 请求行正确加方括号包裹 IPv6 地址
- Mac Proxy ID：加原子计数器后缀，消除毫秒时间戳碰撞
- Mac LSP：-32801 重试请求加 10s 超时保护，Content-Length 加 50MB 上限
- Mac SFTP：多选删除改为遍历全部选中行（原来只删第一行）
- Win 子窗口：关闭主窗口时正确关闭系统信息与连接管理器子窗口
- Win 读线程：Dispose 时 Join(2000) 再释放资源，防止游离线程
- Win async void：全局 12+ 处收敛为 `async Task`，异常不再逃逸到同步上下文

## 体验升级

- **连接错误面板**：连接失败/认证失败/拒绝连接弹出错误卡片（自动阻止消失），可一键重试或清屏重连
- **侧栏监控升级**：网络监控支持双色重叠柱状图（上行蓝/下行绿），延迟监控升级带坐标系样式
- **延迟图表动效**：延迟图表变色改为平滑动画过渡，快捷命令编辑弹窗尺寸优化

## 语义高亮修复（双端）

- 修复中文字符颜色回退规则损坏 ANSI 流的问题
- 修复不完整 ANSI 转义序列被语义高亮截断导致的颜色穿透
- 颜色 7（白色前景）：37m 前景拦截 + 2K 行清空拦截，解决白色文字在彩色背景上不可见
- 跟踪活跃颜色状态，消除重复高亮与单字符误命中（TUI 工具名如 `git`/`ls`）

## 构建

- 双端 build 通过（mac `swift build` / win `dotnet build`）
- 版本号双端统一升至 0.1.6（Info.plist、csproj、banner、更新检查、安装器、README badge）
