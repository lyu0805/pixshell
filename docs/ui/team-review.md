## 用户验收步骤

1. `node /Volumes/d/pixshell/start.js`
2. 看主界面：应是紧凑深色，不是粗边黄按钮
3. 新建连接 → SSH → 下方 SFTP 表有文件
4. 底栏输入 `ls` / `cd /tmp`，SFTP 路径变化
5. 左侧快捷命令可发送
