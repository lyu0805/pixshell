# 面板布局（按用户要求）

## 左侧边栏

1. 主机列表（搜索 / 增删）
2. 侧栏页签：**文件 | 监控 | 进程 | 检测 | 网络 | 系统信息**
   - 文件：远程目录树
   - 监控：CPU/内存/负载/进程 TOP/分区
   - 进程：进程表
   - 检测：多地 Ping / 单目标
   - 网络：网卡与 ss/netstat
   - 系统信息：uname 等采集

## 底部（与文件同屏）

- 左：远程文件表（上传/下载/编辑…）
- 右：**快捷命令（分组）**

## 中间

- 终端（SSH 原生 shell，ssh2）

## SSH

- 使用 ssh2 真实连接，无 mock
- 启动语：`PixShell · 双击左侧主机连接 SSH`
