# PixShell 文档

产品名统一为 **PixShell**。本目录存放架构、UI、功能与实施计划类笔记；**以仓库代码为准**。

## 目录

| 路径 | 说明 |
|------|------|
| `architecture/` | 架构与 Electron / SSH / 像素 UI 基线 |
| `features/` | 功能矩阵与规格 |
| `plan/` | 实施计划与波次状态 |
| `ui/` | 布局与交互规格 |
| `archive/` | **历史研究笔记存档**（只读参考） |

## 关于 `archive/`

`docs/archive/` 仅保留历史调研与对照笔记，**不得作为产品代码、包名、注释或发行文案的引用源**。

产品代码（`packages/**`）禁止第三方商业客户端商标/产品名；自扫规则见项目根 `CLAUDE.md` 与 `代码说明概要.md` §0.1。

活动文档（非 archive）使用中性表述（如「专业运维客户端布局」「原生 ssh2 会话层」），不写第三方商标。
